# OpenMANET (reference)

OpenMANET — Raspberry Pi-based MANET mesh radio system using Wi-Fi HaLow (802.11ah, 915MHz) with Morse Micro chipsets, built on 802.11s mesh + batman-adv routing, OpenWrt-based, with PTT app and ATAK/CivTAK integration. Actively maintained upstream project — this is a reference/watch entry, not something owned by the user.

Repo: https://github.com/openmanet
Main repo: OpenMANET/docs (473 stars / 47 forks)
Releases: separate OpenMANET/firmware repo
